## 一顆球完成對位需要多久？

每次測試從相機取像開始計時，直到該次對位結束，逾時的試次也納入平均。前代與新版分別從同一大袋普通綠球取球。袋內混有不同批次，球面狀況各異，兩組沒有逐顆配對。依當時的操作記憶，兩組測試都關閉了顏色與殘膠檢查。

| 對位時間紀錄 | 前代 | 新版 |
| --- | ---: | ---: |
| 試次 | 10,423 | 29,745 |
| 全部試次總耗時 | 87,470.803 秒 | 96,344.824 秒 |
| 嚴格超過 10 秒的試次 | 3,328 | 124 |

總耗時除以試次，前代平均為 **8.392 秒**，新版為 **3.239 秒**。每次平均少花約 5.153 秒，相對前代縮短 **61.4%**。這段期間同時更換了模型，並改寫粗對位流程與取像調度，因此這個數字代表整套改良後的效果。

逾時門檻為大於 10 秒，恰好 10 秒算在時限內。前代有 3,328 / 10,423 次逾時（**31.93%**），新版為 124 / 29,745 次（**0.42%**）。逾時的球需由人員收回重投。若要從對位速度進一步估算整條產線的合格品產量，還需考慮後續壓印與成品檢查。

## 控制架構改寫前後的四批測試

開發期間另有四批普通球對位紀錄，用來觀察 C# 控制架構改寫前後的耗時。

| 開發階段      |    試次 |  平均對位耗時 |
| --------- | ----: | ------: |
| 改寫前・第一批測試 | 2,213 | 5.029 秒 |
| 改寫前・第二批測試 |   743 | 4.764 秒 |
| 改寫後・第一批測試 | 4,001 | 3.962 秒 |
| 改寫後・第二批測試 | 4,001 | 3.730 秒 |

按各階段的總耗時除以總試次，改寫前 2,956 次平均 **4.962 秒**，改寫後 8,002 次平均 **3.846 秒**，相差約 **1.12 秒（22.5%）**。批次差異的原因已無法追溯，這個差值僅描述兩個開發階段的實測表現。

## 殘膠辨識的實機正確率

另一組測試用約 6～7 顆未印商標的球反覆隨機轉動，以人工檢查當下朝上的球面為準。同一顆球換個朝向，可見面上就可能有膠或無膠。下表記錄新版的 200 次判斷。

| 人工檢查結果 | 系統判有膠 | 系統判無膠 |
| ------ | ----: | ----: |
| 有膠     |    20 |     5 |
| 無膠     |     0 |   175 |

**整體正確率為 97.5%（195 / 200）**，其中 20 次正確判為有膠、175 次正確判為無膠。單看人工確認有膠的 25 次，系統檢出 20 次，有膠檢出率為 80%（20 / 25）。

## 訓練用球與實機測試用球

訓練與驗證共使用約 5～6 顆球拍出的 229,860 張姿態影像。影像隨機分成約七成訓練、三成驗證，因此同一顆球的不同姿態可能出現在兩組中。實機對位測試另外取球，觀察的是機台面對其他球時，能否從相機取像、驅動滾輪，一路完成幾何微調。
